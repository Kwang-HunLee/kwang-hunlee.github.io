Korea Daily scEDI Drought Monitor

Daily drought maps for South Korea based on the spatially continuous Effective Drought Index (scEDI). Station precipitation is converted to scEDI, then rendered as PREC / VDD / AWRI summary panels, DEM-backed contour maps, and optional province-level choropleths.

Select a date below to load the published figure set for that day. New days can be added with drought/scripts/publish_day.py.
